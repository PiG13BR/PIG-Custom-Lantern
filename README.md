# CUSTOM LANTERN
This is a custom lantern for missions.
For SP/MP/DEDICATED.
## HOW TO USE
Paste every file from Missionframework in the mission folder.
Hold Alt + L for 1 second to turn on/off the lights.
## REQUERIMENTS
[CBA](https://steamcommunity.com/workshop/filedetails/?id=450814997)
